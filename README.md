## 🚀 Highlighted Projects

### 🔲 32-bit MAC Unit — Full-Custom VLSI (TSMC 65nm)
> Cadence Virtuoso · Calibre DRC/LVS/PEX · TSMC 65nm @ 1.0 V

- Full-custom 32×32 array multiplier + 64-bit ripple-carry accumulator + 64-bit register with clock gating.
- Complete VLSI flow: transistor-level schematic → custom layout → DRC/LVS → PEX → post-layout sim.
- **3.63 ns** critical-path delay · **2.42 mW** power · **67.3%** power reduction via clock gating.

### 🏗️ 32-bit ARM-Based Processor
> Verilog · ModelSim

- Designed and verified a 32-bit ARM-based processor in Verilog.
- Also built a physical 8-bit ARM-based processor in hardware.

### ⚡ Parallel & Distributed Computing
> MPI · OpenMP · Hadoop · Docker

- MPI-parallelized stats over 5M rows — **1.81× speedup** on 4 processes.
- Hadoop MapReduce on a Dockerized 5-node cluster — 10M rows in **~19 seconds** with **>10⁶:1** shuffle reduction.

### 📹 Video Compression System
> MATLAB · DCT · Huffman / Arithmetic Coding

- Built a complete video codec from scratch: DCT, quantization, block-matching motion estimation, dual entropy coding.
- PSNR range **30.7–63.7 dB** · motion estimation yielded up to **1152% CR improvement**.

### 🌱 AI-Based Smart Precision Irrigation System
> Embedded Systems · OpenSCAD · Sensor Integration

- Team of five building an autonomous, AI-integrated irrigation system — sensor data, plant disease detection, automated watering.
- Handled mechanical design (3D-printed in OpenSCAD) and electronics integration.
- Presented at Zewail City's **"Innovation for Impact"** exhibition (2026).
